GSL

Support

GSL is a private hub for one friend group — feed, chat, plans/polls, photos, and hosts. It is invite-only (not a public App Store discovery product).

How to get help

For account access, membership, or day-to-day app help, contact the group admin who invited you.

For bugs, build issues, or feature requests related to the open project, use GitHub Issues:

https://github.com/tvlins-git/gsl/issues

Quick help

  • Can’t sign in? Ask the group admin to confirm your member account is active and that you’re using the correct password.
  • Missing chats or photos? Check that you’re online; then ask an admin if your membership is still in the group.
  • Notifications? Enable them in iOS Settings for GSL, and review in-app notification preferences under Settings / Profile.
  • Privacy? See the Privacy Policy.

There is no public support email published here. Prefer contacting the group admin, or open a GitHub issue on tvlins-git/gsl if you need a durable record Thomas can update later.
